# project-hail-mary

Zentrale Amazon-Listing-Optimierungs-Plattform (Temoa) — Greenfield-Neubau.

Ein Tool, in dem ein Amazon-Listing vollständig analysiert (Text + Bilder, vor dem
Hintergrund von Zielgruppe, Pain Points, Kaufauslösern und Kundenbewertungen) und
daraus ein organisch perfektes Listing sowie belastbare Handlungsempfehlungen
(PPC, Keyword-Strategie, Share of Voice) erzeugt werden — mit engine-gestütztem Score.

## Wo anfangen

Dies ist noch die **Planungsphase**. Kein Anwendungscode. Der Nordstern:

- [`docs/STRATEGY.md`](docs/STRATEGY.md) — Vision, 3-Layer-Architektur, der eine Workflow, Roadmap.
- [`docs/SALVAGE.md`](docs/SALVAGE.md) — was aus welchem Bestands-Repo portiert wird.
- [`docs/DECISIONS.md`](docs/DECISIONS.md) — Entscheidungs-Log & offene Fragen.

## Prinzipien

1. Eine Quelle der Wahrheit pro Fähigkeit.
2. Import-First, API-Ready.
3. LLM generiert, Code erzwingt (harte Limits deterministisch).
4. Wissen ist ein Layer, kein Feature.
5. Intern zuerst, Kunden später.
